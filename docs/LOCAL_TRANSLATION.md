# Local translation runtime

PR2 adds an optional offline translation provider based on CTranslate2 + SentencePiece.

## Current model

```text
Model: Prukario/opus-mt-es-en-ct2-int8
Revision: ad91ad1697ea1761111ff4c179400796d085b347
Task: Spanish → English
Quantization: INT8
Approximate download: 82.5 MiB
License: CC-BY-4.0
```

The revision is immutable and corresponds to the initial CTranslate2 INT8 conversion. The model repository documents that the conversion requires only CTranslate2 and SentencePiece at inference time and that it is intended to run locally without cloud calls.

The main `model.bin`, `source.spm` and `target.spm` files are checked by exact size and SHA-256 before loading. The required CTranslate2 metadata files must also exist.

## Preparation

```bash
python scripts/manage_local_translation.py status
python scripts/manage_local_translation.py download
```

The download operation shows:

```text
resource
revision
approximate size
destination
reason
license
```

and requests confirmation. `--yes` is an explicit non-interactive confirmation. A valid existing model is reused.

Downloads use HTTPS, the pinned revision, a temporary directory, a per-file size limit, SHA-256 verification for the large files and atomic replacement. Interrupted `.part` files can be resumed when the server accepts HTTP Range requests.

## Configuration

Environment overrides:

```env
TRANSLATION_PROVIDER=local
TRANSLATION_FALLBACK_PROVIDERS=deepl,mymemory
LOCAL_TRANSLATION_MODEL_DIR=tools/models/translation/opus-mt-es-en-ct2-int8
LOCAL_TRANSLATION_MODEL_ID=Prukario/opus-mt-es-en-ct2-int8
LOCAL_TRANSLATION_MODEL_REVISION=ad91ad1697ea1761111ff4c179400796d085b347
LOCAL_TRANSLATION_DEVICE=auto
LOCAL_TRANSLATION_COMPUTE_TYPE=auto
LOCAL_TRANSLATION_BEAM_SIZE=2
LOCAL_TRANSLATION_AUTO_DOWNLOAD=false
```

The normal default chain is `Mistral → local → DeepL → MyMemory`. A missing/corrupt local model is classified as a local resource failure so the next configured provider can be attempted. Invalid provider configuration is classified separately and is not silently converted into another credential configuration.

## CPU/GPU

`auto` selects CUDA only when the hardware profile has positively verified a usable CTranslate2 CUDA backend. Otherwise the local translator uses CPU `int8`.

If CUDA initialization or supported compute-type discovery fails, local translation falls back to CPU `int8` without changing the model or cue order.

AMD/ROCm, Intel and Apple GPUs are detected separately but are not treated as CUDA-compatible Whisper/translation backends without a verified runtime path.

## Batch semantics

The local provider keeps one model instance alive for the execution and translates batches through CTranslate2. Input order is preserved and one output is required for every input. The pipeline maps the returned translations back to their original VTT cues; timestamps and cue IDs are not sent to the model as authoritative metadata and are not regenerated by it.

## Benchmark

Run only after the model is prepared:

```bash
python scripts/benchmark_local_translation.py --sentences 100
```

The benchmark reports model revision, hardware, RAM, device, compute type, cue count, character count, load time, translation time, throughput and time per cue. Results are environment-specific and must not be generalized into a CPU≈GPU claim.

## Cleanup

```bash
python scripts/manage_local_translation.py cleanup
```

Only the managed local translation model directory is removed. Source media, outputs, manifests, configuration and project code are not part of this cleanup operation.
