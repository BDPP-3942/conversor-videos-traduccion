# Resume and idempotency

The pipeline is designed to reuse valid completed artifacts rather than repeat expensive processing.

Conceptually:

```text
missing artifact → execute stage
invalid artifact  → regenerate stage
valid artifact    → reuse stage
```

`resume_enabled` defaults to `true`. `--no-resume` disables normal resume behavior for a run and should be used only for deliberate reprocessing.

Manifests and the processed registry track output state. A runtime lock prevents simultaneous runs from corrupting shared state.

## Subtitle recovery

Subtitle repair is more selective than a full rerun:

- invalid/missing original VTT → STT again, then translation;
- valid original + invalid/missing translated VTT → translation only;
- both invalid → STT once, then translation.

The normal video is not regenerated by subtitle repair.

## TTS

A valid existing TTS artifact can be reused. If subtitle repair changes the VTT used by TTS, the corresponding TTS output must be regenerated so text and timing remain consistent.
